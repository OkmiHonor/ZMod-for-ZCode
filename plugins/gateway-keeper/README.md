# 反代网关守护 (Gateway Keeper)

ZMod 官方生产力插件。智能感知当前会话使用的模型，按需自动探活并拉起本地反代网关（如 Antigravity Tools、Magpie 等），告别使用反代模型时需要手动去点开网关程序、或因忘记启动导致请求连接失败的繁琐流程。

## 🌟 核心特性

- **模型智能感知（Model-Aware）**：自动监控会话输入栏上方的当前模型选择器，在切换模型或切换会话时自动提取并匹配目标网关。
- **轻量端口探活（Smart Probing）**：在拉起网关前自动发起极速 HTTP 探活（默认 1200ms 超时），当目标端口已被监听（返回 200~499 状态码）时保持静默，绝不重复拉起已有实例。
- **智能防抖与冷却（Debounce & Cooldown）**：内置启动冷却时间机制（默认 15 秒），配合 DOM 变动与点击防抖，杜绝短时间内并发拉起或频繁触发。
- **无感后台唤起（Background Wakeup）**：网关离线时自动调用底层系统通道拉起本地可执行文件，并提供友好的 Toast 状态气泡通知。
- **声明式配置面板**：无需手动改写代码，直接在 ZMod 设置中心调整各网关开关、程序路径、探活地址与关键词列表。

## 🔌 默认支持网关

| 网关名称 | 默认状态 | 探活地址 | 默认触发关键词 |
| :--- | :---: | :--- | :--- |
| **Antigravity Tools** | 已启用 | `http://127.0.0.1:8045` | `gemini, claude-opus, claude-sonnet-5, gpt-oss, google` |
| **Magpie** | 未启用 | `http://127.0.0.1:3425` | `magpie, zcode/` |

## ⚙️ 配置说明

在 ZMod 设置页中找到「反代网关守护」即可自由定制：

1. **Antigravity Tools 设置**：
   - **启用自动拉起**：开关，默认开启。
   - **可执行文件完整路径**：默认 `D:\Antigravity Tools\antigravity-tools.exe`（请根据您实际安装位置修改）。
   - **探活服务地址**：默认 `http://127.0.0.1:8045`。
   - **触发模型关键词**：支持中英文逗号、分号或换行分隔，不区分大小写。只要模型名称包含其中任意词即会触发。
2. **Magpie 网关设置**：
   - **启用自动拉起**：开关，默认关闭。
   - **可执行文件完整路径**：默认 `C:\<用户目录>\magpie.exe`。
   - **探活服务地址**：默认 `http://127.0.0.1:3425`。
   - **触发模型关键词**：默认 `magpie, zcode/`。
3. **守护行为与提示**：
   - **拉起时显示状态提示**：拉起网关或拉起失败时通过右上角轻量气泡通知用户。
   - **启动防抖冷却时间 (秒)**：默认 15 秒，避免连续切换时重复唤起。

## 🛡️ 安全与自洁规范

- 权限声明：声明 `system` 权限，仅用于拉起配置的可执行程序。
- 零侵入自洁：所有 DOM 监听器、MutationObserver 与定时器均向 ZMod 内核标准生命周期注销，插件停用时 100% 还原宿主环境。
