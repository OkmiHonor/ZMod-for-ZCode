# 外观与主题工坊（theme-workshop）

一个纯视觉插件：把你的设置实时翻译成一整套覆盖 ZCode 界面的 CSS 皮肤——壁纸层、分区透明度、圆角、字号、字体、面板毛玻璃、窗口材质，停用插件即完整还原原版。

## 快速上手（三步）

1. **启用插件**：在 ZMod 设置里启用「外观与主题工坊」。
2. **选一个预设**：在「第一步 · 预设主题」里五选一——
   - 一键还原原版：什么都不改，随时可用它回到官方样子；
   - 极简毛玻璃：晨雾青灰渐变 + 各分区半透明 + 面板毛玻璃；
   - 护眼暖阳：暖杏橘浅色渐变，透明度偏保守，适合长时间使用；
   - 赛博流光：深空紫蓝渐变 + 更通透的分区 + 大圆角；
   - 透出桌面（原生材质）：关闭壁纸、分区半透明、云母底材——直接透出桌面背景，也是观看窗口材质效果的最快方式。

   选择预设会立即套用整套快照；之后手动微调滑块不会改变「预设」这个选项，想回到预设原貌点「重新应用当前预设」即可。
3. **（可选）放一张自己的壁纸**：见下节。

## 自定义壁纸详解

1. 在「第二步 · 壁纸」里点 **「打开壁纸文件夹」** 按钮（会直接弹出资源管理器）；首次使用若提示失败，完全退出并重新打开一次客户端即可；
2. 把图片文件复制进弹出的文件夹；
3. 回到插件设置，「壁纸来源」选 **自定义图片**；
4. 「壁纸文件名」里填文件名（**含扩展名**，例如 `my-wallpaper.png`）；
5. 点 **「检查壁纸文件」** 立刻确认能不能读到；支持 png / jpg / jpeg / webp / gif / svg，文件名建议用英文或数字；
6. 没点检查也没关系——填对文件名后壁纸没出现时，插件会主动弹提示帮你排查。

内置渐变背景共有 7 张：晨雾青灰 / 暖阳杏橘 / 深空紫蓝 / 松林墨绿 / 薄暮紫粉 / 樱花粉白 / 石墨深灰（樱花粉白、暖阳杏橘适配浅色主题，其余适配深色主题）。

壁纸相关的滑块：亮度（默认 100%）、模糊（0–40px）、四角暗角（默认 30%），以及「填充方式」（铺满裁切 / 完整显示 / 平铺重复，仅自定义图片生效）。

## 滑块含义速查表

| 滑块 | 含义 | 范围 |
|---|---|---|
| 壁纸亮度 % | 壁纸整体明暗，越小越暗 | 20–100 |
| 壁纸模糊 px | 壁纸高斯模糊强度 | 0–40 |
| 四角暗角 % | 画面四周压暗程度，突出中间内容 | 0–80 |
| 面板毛玻璃 px | 四大面板（侧栏 / 会话 / 右侧 / 终端）的背景模糊 | 0–30，0=关闭 |
| 分区透明度（10 个） | 对应区域底色的不透明度，**100 = 原版不透明**，越小越透 | 0–100 |
| 全局圆角 px | 界面控件圆角大小，6 = 官方默认 | 0–24 |
| 全局基准字号 px | 界面文字基准大小，14 = 官方默认 | 12–18 |

透明度分区对照：主背景 / 侧边栏 / 顶栏与标签 / 右侧面板 / 卡片 / 输入框 / 弹窗与菜单 / 用户消息气泡 / 内置终端 / 代码块与行内代码。

字体项填的是**系统字体名**（如 `Microsoft YaHei`），需系统已安装，留空表示不修改。

## 与「亚克力背板与老板键」插件的关系

- **窗口材质功能二选一**：两个插件都能设置 Windows 亚克力 / 云母窗口材质，同时开会互相覆盖，请只保留一个生效（本插件默认「不修改」，不冲突）。
- 其余功能（透明度、壁纸、圆角等）互不冲突，可以搭配使用。

## 窗口材质为什么"看不到"？

先记住三个事实：

1. **ZCode 出厂就把窗口材质设成了亚克力**（宿主自带），所以在这里选「亚克力」本来就看不到变化，真正有新意的是「云母」；
2. **壁纸层会盖住窗口底材**：只要「壁纸来源」不是"关闭壁纸"，最底层的 DWM 材质就被壁纸挡住了；
3. **不透明分区也会盖住**：主背景等分区透明度为 100（全不透明）时同样看不到。

所以想看见材质效果，最快的路径：预设选 **「透出桌面（原生材质）」**（已为你配好云母 + 全套半透明）；或者手动「壁纸来源」→ 关闭壁纸，再把「主背景」调低到 70 以下。

另外：把材质选回「不修改」时，插件会自动把窗口恢复成出厂的亚克力参数。

## 性能提示

- 面板毛玻璃数值越大越耗 GPU（显卡占用、续航），建议 8–16px；
- 壁纸模糊同理，模糊值大 + 高分辨率图片会更卡；
- 都开到很大的值后若感觉界面变卡，优先调低这两个滑块。

## 常见问题

- **壁纸不显示？** 检查文件名是否填对（含扩展名、大小写一致）、文件确实在 `D:\ZMod\data\plugins\theme-workshop\wallpapers\` 里，然后按 `Ctrl+R` 刷新窗口重试。
- **字体填了没生效？** 确认系统已安装该字体，字体名拼写与系统一致（可在 Windows「字体设置」里查），改完按 `Ctrl+R` 刷新。
- **想恢复原版？** 把预设选成「一键还原原版」，或直接停用本插件——停用即还原，不留残留。
